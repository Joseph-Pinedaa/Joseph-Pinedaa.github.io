A web app I built for my own training. It runs in the phone browser and combines a lifting program, macro logging, and a habit tracker. You type what you ate and the app tells you the macros.

  • React
  • JavaScript
  • Claude API
  • Supabase
  • SVG

What it is and why I did it

I wanted one place to run my lifting program, track nutrition, and keep habits, without paying for three apps that don’t talk to each other. So I built it.

My role

Solo: design, front end, API integration, and database.

Process

  1. Training. An 8-week progressive-overload lifting program that steps weight and volume up week to week.
  2. Nutrition. You type a meal in plain text (“two eggs, toast, and a banana”). The app sends it to the Anthropic Claude API, which returns estimated protein, carbs, and fat, tracked against daily targets.
  3. Habits. A custom habit tracker for any daily goal, such as waking up early or hitting macros.
  4. Charts. I hand-coded SVG (vector graphic) charts for weekly macro and lift trends, with no chart library.
  5. Storage. All logs are saved in a Supabase database, so data persists across sessions and devices.

Results and what’s next

Finished in summer 2026 and in regular use.
