SEAS is the soil-sampling drill system on SOMTECH’s Mars rover for the University Rover Challenge. I’m on the firmware side, co-programming the STM32 controller that runs the drill and stepper motors.

  • C
  • STM32 Nucleo-L476RG
  • STM32CubeIDE
  • Stepper motor drivers
  • Rotary encoder

What it is and why I did it

The University Rover Challenge asks student teams to build a Mars-style rover that can collect and analyze soil. SEAS is the subsystem that drills, extracts, and handles the sample. I joined the team in September 2026 to get hands-on embedded experience on a real competition robot.

My role

Firmware member. I’m co-assigned with a teammate to program the STM32 Nucleo-L476RG and the drill and stepper motor drivers in C using STM32CubeIDE.

Process

  1. Working from the team’s existing STM32 project in STM32CubeIDE.
  2. Remapping the microcontroller pinout to add a rotary encoder, giving the drill position feedback.
  3. Correcting timer pin assignments so the motor control signals land on the right hardware timers.
  4. Writing and testing driver code for the drill and stepper motors.

Results and what’s next

In progress for the 2027 competition season. Next up: finishing the encoder integration and closed-loop positioning on the drill.

Code for this project lives in the team’s private repository and is not shared here.
